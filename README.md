# Fit-Flow-Fidelity
This work argues that accessibility compliance is necessary, but not sufficient. A product can meet technical requirements and still feel exhausting, fragile, confusing, or indifferent. Fit, Flow, and Fidelity offer a way to talk about digital quality through disabled experience: not as an accommodation layer, but as a craft lens.
